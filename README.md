# Research-tools

搭建一些有意思、有用的科研工具，让研究工作更高效。

## 项目方向

围绕实际科研需求，逐步开发可独立使用的小工具，例如：

- 文献检索、阅读与整理
- 实验记录、数据处理与结果可视化
- 论文写作与科研工作流自动化

具体工具会随着需求逐步加入；当前仓库处于初始化阶段。

## 组织约定

每个工具放在独立目录中，并提供自己的 README，说明用途、安装方式、使用示例和依赖。通用组件在确有复用需求时再提取。

工具尽量提供可复现的运行步骤和最小示例，不提交密钥、私有数据或大型实验产物。
